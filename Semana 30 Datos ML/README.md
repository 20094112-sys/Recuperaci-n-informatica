Semana 30: Datos y Aprendizaje Automático

1. ¿Qué es el Aprendizaje Automático?

El Aprendizaje Automático (Machine Learning) es una rama de la inteligencia artificial que permite a las computadoras aprender a partir de datos y mejorar sus resultados sin necesidad de programar cada instrucción.

2. Preparación y limpieza de datos

Es el proceso de organizar y corregir los datos antes de utilizarlos para entrenar un modelo.

Algunas tareas son:

* Eliminar datos duplicados.
* Corregir errores.
* Completar valores faltantes.
* Organizar la información.
* Convertir datos a formatos adecuados.

3. División de datos: entrenamiento y prueba

Los datos normalmente se dividen en dos grupos:

* Datos de entrenamiento: se utilizan para enseñar al modelo.
* Datos de prueba: se utilizan para comprobar qué tan bien aprendió.

Una división común es 80% para entrenamiento y 20% para prueba.

4. ¿Qué es el Overfitting?

Ocurre cuando un modelo aprende demasiado los datos de entrenamiento, incluso sus errores y detalles particulares, y tiene dificultades para trabajar con datos nuevos.

5. ¿Qué es el Underfitting?

Ocurre cuando un modelo no aprende lo suficiente de los datos y presenta malos resultados tanto en entrenamiento como en prueba.

6. Conclusión

La preparación de datos es fundamental para obtener buenos resultados en Machine Learning. Un modelo necesita datos limpios y bien organizados para aprender correctamente y realizar predicciones.
