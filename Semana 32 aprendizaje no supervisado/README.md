Semana 32: Aprendizaje No Supervisado

1. ¿Qué es el aprendizaje no supervisado?

Es un tipo de aprendizaje automático en el que una computadora analiza datos sin tener respuestas o etiquetas previamente establecidas. Su objetivo es encontrar patrones, relaciones y grupos dentro de la información.

2. ¿Qué es K-Means?

K-Means es un algoritmo que agrupa datos según sus características y similitudes. Permite dividir un conjunto de datos en grupos llamados clusters.

3. ¿Qué es el método del codo?

Es una técnica que ayuda a elegir la cantidad adecuada de grupos para utilizar en el algoritmo K-Means. Se observa una gráfica para identificar el punto donde la reducción del error comienza a disminuir más lentamente.

4. ¿Qué es PCA?

PCA significa Análisis de Componentes Principales. Es una técnica que permite reducir la cantidad de variables de un conjunto de datos, conservando la mayor cantidad posible de información.

5. Diferencias entre aprendizaje supervisado y no supervisado

* Supervisado: utiliza datos con respuestas conocidas.
* No supervisado: utiliza datos sin respuestas conocidas y busca patrones por sí mismo.

6. Aplicaciones

* Agrupar clientes según sus preferencias.
* Identificar patrones de compra.
* Organizar información.
* Detectar comportamientos inusuales.
* Analizar grandes cantidades de datos.

7. Conclusión

El aprendizaje no supervisado permite descubrir patrones y relaciones dentro de los datos sin utilizar etiquetas. Es una herramienta importante para analizar información y encontrar grupos con características similares.
